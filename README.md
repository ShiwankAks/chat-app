# Realtime Chat App

A full-stack real-time messaging application where users can register,
authenticate, exchange text and image messages, see online users, and
manage their profile.

## Features
- JWT-based authentication
- Real-time direct messaging with Socket.IO
- Online-user presence
- Message persistence with MongoDB
- Image upload through Cloudinary
- User profiles and profile-image updates
- Responsive React interface

## Tech Stack
React, Vite, Tailwind CSS, Node.js, Express, MongoDB, Mongoose,
Socket.IO, JWT, Cloudinary, Vercel
